# Z_Flow

A responsive productivity landing page with an interactive account registration form.

## About the Project

Z_Flow is a front-end project developed as part of the Codveda Technology Front-End Development internship tasks.

The website focuses on a clean and responsive user experience while demonstrating HTML, CSS, and JavaScript fundamentals.

## Features

- Responsive navigation menu
- Hero section
- Features section
- Interactive registration form
- Real-time form validation
- Name validation
- Email validation
- Phone number validation
- Password strength validation
- Show/hide password functionality
- Dynamic error messages
- Success confirmation
- Smooth scrolling
- Responsive layout for mobile, tablet, and desktop
- Accessible semantic HTML
- Reduced-motion support

## Technologies Used

- HTML5
- CSS3
- JavaScript
