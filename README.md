# Z_Flow — Responsive Landing Page

A modern and responsive landing page developed as part of my **Codveda Technologies Front-End Development Internship**.

The project demonstrates responsive web design, interactive form validation, and basic DOM manipulation using vanilla JavaScript.

## 🚀 Live Demo

[View Z_Flow Live Demo](https://zabih-89.github.io/z-flow-landing-page/)

## 📌 Project Overview

Z_Flow is a responsive landing page designed with a clean and modern interface.

The project includes multiple interactive features developed using HTML, CSS, and JavaScript.

It was created to practice and demonstrate fundamental front-end development skills.

## ✨ Features

- Responsive landing page
- Mobile-friendly navigation
- Modern and clean UI
- Interactive signup form
- Real-time form validation
- Name validation
- Email validation
- Phone number validation
- Password strength checking
- Show/hide password functionality
- Success confirmation message
- Interactive counter application
- Increment, decrement, and reset functionality
- Counter cannot go below zero
- Basic DOM manipulation
- Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Git
- GitHub Pages
